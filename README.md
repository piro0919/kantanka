# Kantanka

> Simple tanka (Japanese short poetry) web app.

[🔗 Live Site](https://kantanka.kk-web.link)

## ✨ Features

- ✍️ Write and browse tanka
- 🔐 Stytch-based authentication
- 💾 Prisma-backed storage

## 🛠 Tech Stack

- Next.js + React + TypeScript
- Prisma (database ORM)
- Stytch (authentication)
- react-hook-form

## 🚀 Development

```bash
pnpm install
pnpm dev
```
